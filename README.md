# LAB-Group-Coding-Assignment-4-Swing-Timer-Bouncing-Ball-Animation-with-Shrinking-Functionality



needs:

- A Play area where the ball will be animated.
- A text field for the user to enter the time in seconds for how long
    the ball should shrink.
-Three Buttons:

    - Start: Begins the shrinking and bouncing animation. Also starts the countdown timer.
    - Pause: Pauses the animation and countdown timer; the button should change to Resume to allow the user to resume the animation and countdown timer.
    - Reset: Resets the ball's size and position to its original state, stops the animation, and clears the countdown timer and progress bar.

- A countdown label that shows the time left for the shrinking process,
    rounded to two decimal places.
- A progress bar that visually represents the percentage of time spent on the shrinking process.
